# Correção de dependências vulneráveis — 2026-10-27

Atualizar dependências afetadas no FE/BE, preservando Angular com NgModules, Flask, contratos e apresentação. Não criar testes, conforme pedido do usuário.

Dependabot consultado: 275 alertas abertos no FE (package.json e dois lockfiles) e 34 no BE (requirements.txt). Contagens podem mudar enquanto o GitHub reanalisa os repositórios.

Angular 15 não recebe os patches necessários; alvo mínimo suportado: Angular 20 LTS, com Node 22 e TypeScript compatível. Manter ambos os lockfiles consistentes porque README recomenda pnpm e CI usa npm.

Verificações previstas: auditorias completas npm/pip, dependências compatíveis, TypeScript, builds Angular e carregamento Flask. Navegador indisponível na sessão anterior; não afirmar validação visual ou upload real.

## Resultado

- FE: Angular 20.3.34 / Material 20.2.14 / CLI e builder 20.3.41; TypeScript 5.9.3 e Zone.js 0.15.1. Node 22 no CI. Componentes continuam declarados no NgModule (`standalone: false`).
- Builder oficial `@angular/build` substitui a cadeia Webpack vulnerável. Migração oficial aplicada; saída permanece `docs/index.html`, com o mesmo tema Material. Detecção de atualização aceita nomes antigos `main.*` e novos `main-*`.
- BE: requisitos afetados atualizados, incluindo Werkzeug 3.1.9; Blinker e ItsDangerous alinhados aos requisitos do Flask 3.1.3.
- `npm audit`: de 85 vulnerabilidades na árvore npm para zero, incluindo desenvolvimento. `pnpm audit`: zero. Ambos os lockfiles atualizados, sem ignorar alertas ou forçar peers.
- `pip-audit -r requirements.txt`: zero vulnerabilidades conhecidas na resolução completa. `pip check`: passou. Flask carregou com as dependências novas em ambiente Python 3.12 isolado.
- TypeScript, build de desenvolvimento, instalação limpa `npm ci` e consistência `pnpm install --lockfile-only --offline --frozen-lockfile --ignore-scripts`: passaram.
- Build com o comando de produção do CI e base `/my-small-group-FE/`: passou; conferidos `docs/index.html`, `404.html` e scripts. Bundle de 580,34 kB mantém aviso acima da meta de 500 kB.
- Servidor frontend respondeu 200 para página e JavaScript; API local respondeu 200 no OpenAPI e no preflight CORS com Authorization, Content-Type e X-Group-ID.
- Nenhum teste criado. Nenhuma mutação de dados ou login em produção. Navegador segue indisponível: sem validação visual ou upload real.

Referências: [compatibilidade Angular](https://angular.dev/reference/versions), [migração oficial do builder](https://angular.dev/tools/cli/build-system-migration), [patch Werkzeug 3.1.9](https://github.com/pallets/werkzeug/security/advisories/GHSA-g6x2-hccm-hh4m).
